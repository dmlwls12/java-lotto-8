# java-lotto-precourse

<br>

## Description
---
- 콘솔 입출력을 통해 로또 구입 → 당첨 번호 입력 → 결과 통계 출력까지의 흐름을 구현하였다.
- 예외 발생 시 `[ERROR]`로 시작하는 메시지를 출력한다.  
- 입력값 검증 및 재입력 처리를 시행한다.  
- 수익률 계산 및 소수점 반올림 처리를 시행한다.
- 명확한 예외 타입(`IllegalArgumentException`, `IllegalStateException`)을 사용한다.  
- `Java Enum` 기반 등수 판정 및 상금을 계산한다.

<br>

## Function list
---

### 1️⃣ 입력

1) 구입 금액 입력
- 1,000원 단위의 양의 정수만 허용한다.
- 1,000으로 나누어떨어지지 않으면 예외 처리한다.
- 최소 1장 이상 구매 가능해야 한다.

2) 당첨 번호 입력
- 번호는 쉼표(,)를 기준으로 6개의 숫자를 입력받는다.
- 각 번호는 1~45 범위이고 중복이 불가하다.

3) 보너스 번호 입력
- 1~45 범위이고, 당첨 번호와 중복이 불가하다.
- 숫자 하나만 입력받는다.

### 2️⃣ 로또 발행
- 로또 한 장은 중복 없는 6개 번호(1~45)로 랜덤으로 뽑는다.
- 로또는 1개에 1,000원이고, 사용자가 구매한 로또 개수만큼 로또를 발행한다.

### 3️⃣ 출력
- 사용자가 로또를 구매한 개수를 출력한다.
- 로또 번호는 오름차순으로 정렬하고, 당첨 번호와 일치하는 개수별로 출력한다.
- 수익률은 소수점 둘째 자리에서 반올림한다.
- 예외 상황 시 "[ERROR]"로 시작하는 에러 문구를 출력한다.
  ex) [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.

### 4️⃣ 당첨 판정 규칙

- 번호 일치 개수와 보너스 일치 여부로 판정한다.

- 상금 및 기준:

1등: 6개 일치 → 2,000,000,000원

2등: 5개 일치 + 보너스 일치 → 30,000,000원

3등: 5개 일치 → 1,500,000원

4등: 4개 일치 → 50,000원

5등: 3개 일치 → 5,000원

2등/3등 우선순위: 5개 일치 시 보너스까지 일치하면 2등, 아니면 3등.

### 5️⃣ 예외/검증 규칙
- 모든 에러는 IllegalArgumentException 등 명확한 타입으로 던지고, 출력은 "[ERROR] ..." 형식으로 한다.
